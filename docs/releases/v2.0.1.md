# Kagami v2.0.1 · Stable

Fixes the title bar and window-control regression in v2.0.0.

## Fixed

- Merge the Kagami logo/title and Start/Stop/settings into one native GTK header bar. The extra gray system title strip is removed.
- Keep app-button CSS outside native window controls, preserving the theme's minimize/maximize/close artwork. MacTahoe uses background images and transparent button glyphs; v2.0.0 replaced those images and made the controls appear blank.
- Keep native window dragging, keyboard/window-manager actions and close cleanup. Give glyph-based decoration themes readable control colors on the purple header.

## Install or update

Run as your ordinary desktop user:

```bash
curl -fsSL https://github.com/celestial-sora/kagami/releases/download/v2.0.1/install-kagami.sh | bash
```

The release installer selects v2.0.1 by default and builds pinned receiver backends locally. It retains settings and the previous application for `kagami rollback`. System setup requests sudo; Secure Boot camera enrollment may require a reboot. No prebuilt receiver binary is bundled.

## Validation and limits

All 70 contract/synthetic media and release-packaging tests pass locally. GTK checks cover the single title bar, controls outside the app CSS scope, native close cleanup, saved preferences and Start/Stop framing. Rendering was inspected under MacTahoe-Dark and Adwaita. Publication requires successful contracts, packaging and receiver CI for the exact main commit, then a download/SHA256 check of draft assets.

Transport/media behavior is unchanged. The maintainer previously confirmed iPad video in Kagami and OBS on Ubuntu 26.04. Smart View remains experimental and requires advertised Linux P2P-client/P2P-GO. Other Apple devices, Galaxy/P2P, audio sync/capture, long static-screen sessions, Discord and enabled Secure Boot still need physical acceptance. AirPlay input remains a fixed 1280×720 canvas; 1080p is virtual-camera output. USB/ADB requires separately installed ADB and scrcpy 3.0+.

Download the attached files and `SHA256SUMS`, then run `sha256sum --check SHA256SUMS`. `COMMIT` records the exact source SHA; `kagami-v2.0.1-source.tar.gz` includes committed sources and licenses. No captured media is bundled.
