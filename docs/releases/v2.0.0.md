# Kagami v2.0.0 · Stable

First stable release of the native GTK4 Kagami desktop for Ubuntu 24.04 / 26.04.

## Install or update

Run as your ordinary desktop user in a terminal:

```bash
curl -fsSL https://github.com/celestial-sora/kagami/releases/download/v2.0.0/install-kagami.sh | bash
```

The release installer selects **v2.0.0** by default. It installs dependencies and builds the pinned receiver backends on your machine; it is not a prebuilt binary package. System setup requests sudo. Secure Boot camera enrollment may require a reboot. The same command updates an earlier app while retaining settings and a previous version for `kagami rollback`.

## Included

- Purple two-column camera UI with the approved Kagami app icon, source cards, camera settings, guide/safe-area overlays, live crop preview and connection/framing controls.
- AirPlay reception with desktop audio, corrected timestamps, static-screen session handling and 1080p virtual-camera output.
- Samsung Smart View, USB and authorized Wi-Fi ADB transport choices feeding the shared crop/rotation/mirror/fit/FPS pipeline.
- Locally saved desktop preferences, bounded media queues, owned-process cleanup and guarded Kagami V4L2 loopbacks.
- Version comparison, unchanged-update skips, backend reuse and application rollback.

## Validation and limits

The release candidate must pass all three CI jobs: contracts, packaging and receiver builds/media/GTK checks. The app has 70 contract/synthetic media and release-packaging tests. The maintainer confirmed real iPad video in Kagami and OBS on Ubuntu 26.04.

**Smart View remains experimental** and requires a Linux driver advertising P2P-client/P2P-GO. The authoring RTL8821CE driver does not currently advertise those modes. Other Apple devices, physical Galaxy/P2P, desktop audio capture/sync, long static-screen sessions, Discord and enabled Secure Boot still need device acceptance. AirPlay input is a fixed 1280×720 canvas; 1920×1080 describes virtual-camera output. USB/ADB requires separately installed ADB and scrcpy 3.0+. A stable release does not imply those unverified capabilities are validated.

## Files and verification

`install-kagami.sh` is the pinned Ubuntu installer. `kagami-v2.0.0-source.tar.gz` contains source, documentation and licenses. `COMMIT` identifies the exact source SHA. Download the files and `SHA256SUMS`, then run `sha256sum --check SHA256SUMS` before use. GitHub's automatically generated source archives are separate from these checksummed assets. No third-party backend binaries or recorded media are bundled.
