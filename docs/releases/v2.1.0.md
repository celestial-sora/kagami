# Kagami v2.1.0 · Linux distributions and AppImage

Prepared release notes; stable publication requires explicit authorization and the guarded main/successful-CI release workflow. Contributor: celestail-sora.

- Native installer dispatches apt for Ubuntu/Debian families, pacman for Arch families and dnf for Fedora families. Ubuntu remains primary. Red Hat/Enterprise Linux and other RPM families are outside scope.
- Matching kernel headers, exact module verification, safe named camera guards, selected-adapter consent, preserved settings and app rollback remain required. Arch uses a full upgrade; Fedora stages pinned v4l2loopback DKMS sources without replacing existing registrations. Repository signatures and SELinux remain enabled.
- x86_64 AppImage bundles Python/GTK4/GStreamer and the patched UxPlay backend, with licenses, relative RPATH and checked build tools. Ubuntu 24.04/glibc 2.39 is the portable build baseline; Debian 12 uses the native installer. Kernel drivers, camera nodes, discovery and privileged Smart View helpers remain host prerequisites.
- CI adds Debian 12/13, Arch and Fedora runtime/backend checks and extracted/relocated AppImage GTK checks. The release workflow consumes the exact successful main CI binary and verifies release checksums before publication.

Actual new-distribution host installations, Secure Boot, Galaxy/P2P, camera/OBS and Apple audio/interoperability remain hardware acceptance work. Existing Ubuntu iPad video evidence does not establish other-distro phone compatibility. See [distribution setup](../linux-distributions.md) and [validation](../validation.md).
